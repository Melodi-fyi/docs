## Export Limits and Delivery

- You can export up to **1,000,000 rows** of data at a time
- Large exports will be sent to you by email
- For data migrations off of Melodi, we recommend using the **JSONL export format**, which contains all data in the same format as you would retrieve from the Melodi APIs

## Exporting Users Data

To export your users data:

1. Navigate to the Users section in your Melodi dashboard
2. Click the export button
3. Select your preferred format (CSV or JSONL recommended for migrations)
4. Choose your date range and filters if needed
5. Click "Export" to start the process

## Exporting Session Data

To export your session data:

1. Go to the Sessions section in your dashboard
2. Click the export button
3. Select JSONL format for complete data migration
4. Set your date range and any additional filters
5. Start the export process

<img src="/images/session_export.png" alt="Session export interface" />

## Export Formats

### JSONL (Recommended for Migration)
- Contains all data in the same format as Melodi APIs
- Best for importing into other systems
- Preserves all metadata and relationships

### CSV
- Good for analysis in spreadsheet applications
- Human-readable format
- May not include all nested data structures

## Exporting Dashboard Chart Data

You can also export individual chart data from your monitoring dashboards:

1. Navigate to any monitoring dashboard
2. Click the visualization menu (three dots at top right)
3. Select your preferred export format (CSV, PNG)
